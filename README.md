# kgateway-tooling

Coordination for the kgateway tooling projects: xdsview (Envoy data-plane library), Snellius (web UI) and kgwctl (CLI). No code lives here.

- [`program.md`](program.md) — components, contracts, dependency edges, policy provenance and mirror rules, xDS convergence, ownership, upstream asks, order of work and the coordination protocol.
- [`go.work.example`](go.work.example) — a Go workspace for building the projects against each other locally.
